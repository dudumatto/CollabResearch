# CVE-2026-53669 in react-router 7.15.1 (open redirect via backslashes in navigation components)

**ID:** vuln-0004
**Severity:** MEDIUM
**Found:** 2026-09-06 21:41:32 UTC
**Target:** desktop
**Package:** react-router
**Ecosystem:** npm
**Installed Version:** 7.15.1
**Fixed Version:** 7.18.0
**Introduced By:** react-router-dom@7.15.1
**Dependency Chain:** react-router-dom@7.15.1 > react-router@7.15.1
**CVE:** CVE-2026-53669
**CVSS:** 5.1
**Fix Effort:** Low

## Description

The desktop client resolves `react-router` `7.15.1` through `react-router-dom`, which is within the affected range for `CVE-2026-53669`. The advisory describes an open redirect issue via backslashes in navigation components and is fixed in `7.18.0`.

## Evidence

**Advisory evidence:** `CVE-2026-53669` applies to `react-router` at installed version `7.15.1`. The advisory is fixed in `7.18.0`.

**Transitive dependency:** introduced by the direct dependency `react-router-dom@7.15.1`.

**Dependency chain:** `react-router-dom@7.15.1 > react-router@7.15.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. `desktop/src/app/router.tsx:1-38` imports `createHashRouter` from `react-router-dom`; `desktop/package-lock.json:2538-2545` resolves `react-router@7.15.1` via `react-router-dom@7.15.1`. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

If the affected navigation components are reachable, crafted backslash-delimited destinations can redirect users to attacker-controlled pages and weaken trust in in-app navigation.

## Technical Analysis

`react-router-dom@7.15.1` pulls in `react-router@7.15.1`. The vulnerability is resolved by moving the dependency chain to a fixed release.

## Remediation

Upgrade `react-router-dom` and the resolved `react-router` dependency to `7.18.0` or later, then refresh the lockfile so the vulnerable version is removed.

## Assumptions

Assumes the application exposes the affected navigation helpers. Static analysis confirmed the package is imported; the redirect primitive itself was not dynamically validated during triage.
