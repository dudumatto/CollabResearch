# CVE-2026-53667 in react-router 7.15.1 (untrusted redirect via missing protocol validation)

**ID:** vuln-0003
**Severity:** MEDIUM
**Found:** 2026-09-06 21:41:20 UTC
**Target:** desktop
**Package:** react-router
**Ecosystem:** npm
**Installed Version:** 7.15.1
**Fixed Version:** 7.18.0
**Introduced By:** react-router-dom@7.15.1
**Dependency Chain:** react-router-dom@7.15.1 > react-router@7.15.1
**CVE:** CVE-2026-53667
**CVSS:** 6.9
**Fix Effort:** Low

## Description

The desktop client resolves `react-router` `7.15.1` through `react-router-dom`, which is within the affected range for `CVE-2026-53667`. The advisory describes untrusted redirects due to missing protocol validation and is fixed in `7.18.0`.

## Evidence

**Advisory evidence:** `CVE-2026-53667` applies to `react-router` at installed version `7.15.1`. The advisory is fixed in `7.18.0`.

**Transitive dependency:** introduced by the direct dependency `react-router-dom@7.15.1`.

**Dependency chain:** `react-router-dom@7.15.1 > react-router@7.15.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. `desktop/src/app/router.tsx:1-38` imports `createHashRouter` from `react-router-dom`; `desktop/package-lock.json:2538-2545` resolves `react-router@7.15.1` via `react-router-dom@7.15.1`. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

If the affected navigation helpers are reachable, attacker-controlled routes or redirect targets can send users to unexpected destinations and enable phishing pivots or token leakage through redirect abuse.

## Technical Analysis

`react-router-dom@7.15.1` resolves `react-router@7.15.1`, which falls within the advisory's affected range. Upgrading the resolved package removes the vulnerable code path.

## Remediation

Upgrade `react-router-dom` and the resolved `react-router` dependency to `7.18.0` or later, then regenerate the lockfile so the vulnerable version is no longer selected.

## Assumptions

Assumes the application uses the routing helpers covered by the advisory. The package is imported in the desktop client, but the redirect primitives were not dynamically exercised during triage.
