# CVE-2026-55685 in react-router 7.15.1 (unauthenticated manifest endpoint DoS)

**ID:** vuln-0001
**Severity:** HIGH
**Found:** 2026-09-06 21:40:57 UTC
**Target:** desktop
**Package:** react-router
**Ecosystem:** npm
**Installed Version:** 7.15.1
**Fixed Version:** 7.18.0
**Introduced By:** react-router-dom@7.15.1
**Dependency Chain:** react-router-dom@7.15.1 > react-router@7.15.1
**CVE:** CVE-2026-55685
**CVSS:** 8.7
**Fix Effort:** Low

## Description

The desktop client pins `react-router` `7.15.1` through `react-router-dom` and is therefore within the affected version range for `CVE-2026-55685`. The advisory describes an unauthenticated manifest endpoint denial of service issue that is fixed in `7.18.0`.

## Evidence

**Advisory evidence:** `CVE-2026-55685` applies to `react-router` at installed version `7.15.1`. The advisory is fixed in `7.18.0`.

**Transitive dependency:** introduced by the direct dependency `react-router-dom@7.15.1`.

**Dependency chain:** `react-router-dom@7.15.1 > react-router@7.15.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. `desktop/src/app/router.tsx:1-38` imports `createHashRouter` from `react-router-dom`; `desktop/package-lock.json:2538-2545` resolves `react-router@7.15.1` via `react-router-dom@7.15.1`. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

If the affected React Router server/runtime path is reachable in this application or in a bundled dependency path, unauthenticated requests can trigger excessive manifest processing and degrade availability.

## Technical Analysis

The desktop application resolves `react-router` `7.15.1` through `react-router-dom` `7.15.1`, which falls inside the advisory's affected range. The package is imported by the desktop router setup and should be upgraded to a fixed release.

## Remediation

Upgrade `react-router-dom` and its resolved `react-router` dependency to `7.18.0` or later, then regenerate the lockfile so the desktop client no longer resolves the vulnerable version.

## Assumptions

Assumes the affected React Router code path is reachable in this build. Static analysis confirmed the package is imported, but the advisory-specific runtime path was not dynamically exercised during triage.
