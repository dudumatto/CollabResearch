# CVE-2026-53666 in react-router 7.15.1 (client-side constructor execution information disclosure)

**ID:** vuln-0002
**Severity:** MEDIUM
**Found:** 2026-09-06 21:41:09 UTC
**Target:** desktop
**Package:** react-router
**Ecosystem:** npm
**Installed Version:** 7.15.1
**Fixed Version:** 7.18.0
**Introduced By:** react-router-dom@7.15.1
**Dependency Chain:** react-router-dom@7.15.1 > react-router@7.15.1
**CVE:** CVE-2026-53666
**CVSS:** 6.1
**Fix Effort:** Low

## Description

The desktop client resolves `react-router` `7.15.1` through `react-router-dom`, which is inside the affected range for `CVE-2026-53666`. The advisory describes information disclosure via client-side constructor execution and is fixed in `7.18.0`.

## Evidence

**Advisory evidence:** `CVE-2026-53666` applies to `react-router` at installed version `7.15.1`. The advisory is fixed in `7.18.0`.

**Transitive dependency:** introduced by the direct dependency `react-router-dom@7.15.1`.

**Dependency chain:** `react-router-dom@7.15.1 > react-router@7.15.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. `desktop/src/app/router.tsx:1-38` imports `createHashRouter` from `react-router-dom`; `desktop/package-lock.json:2538-2545` resolves `react-router@7.15.1` via `react-router-dom@7.15.1`. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

If the vulnerable client-side routing path is exercised, attacker-controlled navigation data can disclose information through constructor execution in the browser context.

## Technical Analysis

`react-router-dom@7.15.1` resolves `react-router@7.15.1`. The advisory applies to that version range and is resolved by upgrading to a fixed release.

## Remediation

Upgrade `react-router-dom` and the resolved `react-router` dependency to `7.18.0` or later, then refresh the lockfile to eliminate the vulnerable version.

## Assumptions

Assumes the application uses the affected client-side routing features exposed by `react-router-dom`. Static analysis confirmed the package is imported; dynamic exploitation was not attempted for this advisory.
