# Claude Agents — CollabResearch

Este repositório é um monorepo: `backend/` (Spring Boot), `web/` (React/Vite), `desktop/` (Electron), `mobile/` (Flutter), `nextweb/` (Next.js).

Siga `.codex/AGENTS.md` para agents (`.agents/agents/`), skills (`.agents/skills/`), regras (`.rules/`), roteamento e checklist de entrega.

Resumo do fluxo: identifique o módulo afetado, siga os padrões dele, implemente, execute build/lint/testes relevantes, corrija e repita até estado funcional. Não faça commit/push/reset destrutivo sem autorização explícita.
